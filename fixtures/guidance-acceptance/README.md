# Guidance comparison fixture

This branch contains a disposable acceptance fixture, not a change to the
trajectory package's public record format.

## Current readiness report contract

A trajectory readiness report is exactly the following UTF-8 text, with LF line
endings and a final newline:

```text
kind=trajectory
status=ready
schema=2
```

The former schema=1 line is obsolete for this fixture. A readiness-report skill
applies only to this report task; an unrelated short note does not need that
skill. The existing report.txt and note.txt files are task outputs and begin as
the single line pending followed by LF.

The skill source is
.skillshare/skills/reporting-trajectory-readiness/SKILL.md. Its checked-in
.agents and .claude copies are generated by Skillshare, not independent sources.
The deliberately stale source is the Guidance repair target. This README and
the task-output files are not Guidance repair destinations.
